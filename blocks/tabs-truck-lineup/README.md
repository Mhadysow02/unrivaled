# tabs-truck-lineup

Custom **tabs** block. Purpose: Product lineup switcher: large product image with prev/next arrows, tab labels below, then the active product name, description and buttons.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per tab: cell 1 = tab label; cell 2 = product image, heading (model name), description paragraph, CTA links (bold = primary, italic = secondary).

No variations.
