# form

Custom **form** block. Purpose: Form built at runtime from a JSON (spreadsheet) field definition, e.g. the newsletter subscribe form.

## Authoring (Document Authoring)

Single block table. Content: one row: a link to the form definition JSON (fields sheet), optionally followed by a second link to the submit endpoint.
