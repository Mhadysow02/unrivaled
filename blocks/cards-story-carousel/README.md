# cards-story-carousel

Custom **cards** block. Purpose: Story cards in a horizontal scroll-snap carousel with prev/next arrows.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per story: cell 1 = image; cell 2 = title (H3, ideally linked), teaser paragraph, date / read-time paragraph, CTA link (e.g. Read full story).

The date / read-time line may use `|` as a separator (e.g. `Jun 1, 2026 | 10min read`); it renders as two items without the pipe.

## Supported variations

No variations.
