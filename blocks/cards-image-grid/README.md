# cards-image-grid

Custom **cards** block. Purpose: Grid of large image cards with a caption area and centered title and text.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per card: cell 1 = image; cell 2 = title (H3) and description.

No variations.
