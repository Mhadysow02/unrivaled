# hero-video

Custom **hero** block. Purpose: Full-bleed background video (with poster-image fallback) and overlaid heading, text and CTAs.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 = background media: a link to an .mp4/.webm video plus an optional poster image (the poster is also the fallback); row 2 = heading (H1 or H2), paragraph(s), CTA links.

## Supported variations

No variations.
